# Cairn Recording Contract

ScholarForge should hand Cairn durable artifacts, not raw search noise.

Recommended mapping:

- `brief.md` -> Cairn artifact
- each strong `evidence.jsonl` row -> candidate evidence artifact
- stable, checked conclusion -> Cairn claim
- unresolved mechanism or experimental prediction -> Cairn hypothesis
- contradictions -> Cairn link with relation `contradicts`

Do not record every source as a separate Cairn artifact unless it changes the research trajectory.
